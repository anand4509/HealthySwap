# 🥗 FoodWise – Healthy Food Analyzer

FoodWise is a simple web-based application that helps users **compare healthy and junk foods**, explore nutritional information, and find **healthier alternatives** to common junk foods.

## ✨ Features

* 🍎 Healthy & junk food information
* 🔍 Search and filter foods
* ⚖️ Compare nutritional values
* 🔄 Healthy replacement suggestions
* 🥗 Basic diet suggestions
* 📊 Nutrition charts
* 🌙 Dark mode
* 📱 Responsive design

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* Chart.js
